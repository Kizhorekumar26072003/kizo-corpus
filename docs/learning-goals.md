## Goals for this project (beyond shipping)

1. Close the gap between syntactic and semantic understanding of code
2. Develop intuition for time and space complexity
3. Learn to see problems through the lens of data structures and algorithms
4. Build mental models for system design and tradeoffs
5. Develop UI/UX intuition rooted in user psychology
6. Strengthen core CS fundamentals (memory, networks, databases, OS)

## How I'll measure progress

- Can I explain _why_ I made each decision in the project?
- Can I predict the performance of code before running it?
- Can I look at a problem and recognize its "shape" (graph/tree/hash/etc.)?
- Can I justify every UI choice with a user-psychology reason?
- Can I read someone else's code and identify what's good vs. what's a smell?
